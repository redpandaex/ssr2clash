SSR2Clash 便携版 1.1.0

1. 将 ZIP 完整解压到有写入权限的文件夹，运行 ssr2clash.exe。
2. 保留 exe 同目录的 portable.flag，配置和快照将保存到旁边的 data 文件夹。
3. 填写单个 SSR 原订阅地址，点击立即更新，再启动本地服务。
4. 将界面显示的本地订阅链接添加到 Clash Verge。
5. 实时模式下，每次请求都会重新拉取原订阅。开启冻结快照后只返回保存的 YAML。

关闭窗口默认隐藏到托盘。要完全结束程序，请使用托盘菜单的退出。
开机自启在设置中手动开启。便携目录移动后，可在新位置重新开启自启。
移动时携带整个文件夹；覆盖升级只替换应用文件，保留原 data 文件夹。
安装版与便携版使用独立数据目录，链接只有在保留同一份数据时才保持不变。

需要 Windows 10/11 x64 和 Microsoft Edge WebView2 Runtime。
