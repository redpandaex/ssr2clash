## 安装器依据与边界

最终整分支复查确认并修复了三项问题：基础配置中的 `MATCH` 不再遮蔽后续生成规则；无效的策略组、规则与未知分组选项会在更新缓存前报错；导入展开和成员生成具有总量限制。新增 11 项回归测试先复现失败，再验证修复。默认 10 组、9797 条规则的对照测试仍通过。

实现决策、限制与复查处理见 [实现决策记录](implementation-decisions.md)。一个次要项目暂缓：已有另一份程序运行时，第二次启动会唤回原窗口，但没有额外提示正在运行的 exe 路径；可在设置中查看运行模式和数据目录。

当前 Tauri 官方模板包含目录选择页、恢复上次安装位置和默认不勾选的数据清理选项。本迭代保留这些行为，构建为 `currentUser`。为了防止官方模板按名字误删另一份便携版的自启项，固定了 CLI 2.12.3 模板，仅把无条件删除替换为路径归属宏；来源和原始哈希在 `src-tauri/installer/upstream.json`。

静默钩子测试实际运行同一份宏，读写的是测试注册表根，而非 Windows Run。它验证了中文、空格与 D 盘路径的处理和所有权逻辑，不能替代完整安装向导、覆盖升级与卸载的验收。

## 手动验收

用户要求手动预览后，停止了自动打开/关闭桌面窗口。下列项目仍需手动验证：

1. 新 UI 在真实 Tauri 窗口中的系统剪贴板、文件保存对话框、原生主题与托盘可见性。后端原生 IPC 已验证，当前 UI 的复制/导出意图通过模拟 API 的无窗口检查。
2. 在隔离 Windows 环境执行安装向导，选择自定义目录、中文/空格路径和其他盘符；验证权限不足目录的提示。
3. 安装后生成虚构订阅快照，覆盖升级、重开，确认端口、令牌和快照保留；分别验证卸载默认保留数据和明确勾选清理数据；检查快捷方式与原生壳图标。
4. 使用最终便携包整体移动和覆盖应用文件后，确认数据与链接保留。exe 相对数据路径、当前目录变化和原子重开已有后端测试。
5. 用户真实 SSR 订阅与 Clash Verge 实际导入、刷新和冻结；实际重启登录后的自启。

没有执行真实用户安装的覆盖、卸载，没有创建发布 tag、推送分支或发布 Release。
